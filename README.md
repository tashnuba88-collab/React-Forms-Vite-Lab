# Shopster - Shopping List App

A React app for managing a shopping list with search, category filtering, and the ability to add new items.

## Setup Instructions

1. Clone the repo
2. Install dependencies:
   npm install
3. Start the dev server:
   npm run dev
4. Open the local URL shown in the terminal (e.g. http://localhost:5173)

## Running Tests

npm test

## Features

- Search items by name (updates live as you type)
- Filter items by category (Produce, Dairy, Dessert)
- Add new items to the list via a form
